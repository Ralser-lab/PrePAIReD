The workflow used to pre-process LC/MS data generated by DIA-NN is written in R and contains several modules:
1) module_import.R: import DIA-NN data into R in `msdap` format
2) module_filtering_samples.R: Filter outlier samples
3) modeul_filtering_peptides.R: Filter peptides with low presence
4) module_imputation.R: Impute missing values in the peptide/protein abundance matrix
5) module_normalisation.R: Normalize peptide/protein abundances
6) module_summarisation.R: generate summary report of the data
